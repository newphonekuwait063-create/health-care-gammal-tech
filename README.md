# خط أنابيب تحليل وتوقع مخاطر مرض السكري (Diabetes Risk Analysis & Prediction Pipeline)

مشروع متكامل لهندسة البيانات والنمذجة التوقعية، صُمم لتخزين وتنظيف وتحليل المؤشرات السريرية للمرضى (مثل: مستويات الجلوكوز، ضغط الدم، مؤشر كتلة الجسم BMI، والعمر)، بهدف تقييم عوامل الخطر المرتبطة بمرض السكري وتوقع النتائج الصحية المحتملة للمرضى.

---

##  المعمارية والتصميم (Architecture & Design)

يعتمد المشروع على هيكل قاعدة بيانات علائقية (PostgreSQL) تم تحسينه لإجراء الاستعلامات التحليلية المنظمة، يليه خط أنابيب بيانات (Data Pipeline) لاستخراج الخصائص (Features) وتشغيل نموذج التوقع.
